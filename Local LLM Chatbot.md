## 🚀 Total Privacy. Zero Restrictions.

**Local AI Chatbot** is a powerful, fully offline desktop application that brings the raw, unfiltered power of Large Language Models (LLMs) directly to your hardware. 

Tired of woke AI filters, account bans, and monthly API bills? This app runs entirely on your local machine. By leveraging open-weight models like Llama 3, Mistral, and Gemma via the Ollama engine, it delivers blazing-fast responses without sending a single byte of your data to the cloud.

Whether you are writing uncensored fiction, researching sensitive topics, or coding proprietary software, you can trust that your conversations remain 100% private. No corporate overlords, no hidden telemetry, no "safety" lectures.

> 💡 **Why use a local chatbot?** Because true freedom of information requires absolute privacy. Take control of your AI experience.

## 🚀 Quick Start

> **Three steps. Under five minutes. No API keys required.**

### 1️⃣ Download and install
Grab the latest `.exe` (Windows), `.dmg` (macOS), or `.AppImage` (Linux) from the button at the top.

### 2️⃣ Download your first model
Open the app and go to the "Models" tab. Click "Download" next to **Llama 3 8B** (recommended for most PCs).

### 3️⃣ Start chatting
Go back to the main window, wait for the model to load into memory, and start typing!

## ⚙️ How It Works

<div align="center">

| Layer | Responsibility | Tech |
|:---|:---|:---|
| 🖥️ **Frontend UI** | Chat interface and settings | `React` + `Tauri` |
| 🧠 **Inference Core** | Runs the LLM locally | `Ollama` |
| 🎨 **Model Manager** | Downloads and quantizes models | `Python` |
| 🗄️ **Database** | Stores local chat history | `SQLite` |

</div>

The application is wrapped in Tauri, making it incredibly lightweight (under 50MB) unlike heavy Electron apps. The heavy lifting is done by Ollama running silently in the background, which utilizes your system's RAM and GPU for fast generation.

## ❓ Frequently Asked Questions

<details>
<summary><b>Can I run this on a weak laptop?</b></summary>

Yes, but it will be slow. You can run smaller models (like `Phi-3` or `TinyLlama`) on CPUs with 8GB of RAM. However, for a smooth experience, a dedicated GPU is highly recommended.
</details>

<details>
<summary><b>Is it really uncensored?</b></summary>

Yes. We do not inject "safety" system prompts. However, the models themselves (like Llama 3) have inherent training biases. You can bypass some of this by using specific "uncensored" fine-tunes available in the app.
</details>

<details>
<summary><b>Does it cost money?</b></summary>

The app is 100% free and open-source. You only pay for your own electricity. There are no subscriptions or hidden fees.
</details>

<details>
<summary><b>Can it browse the internet?</b></summary>

By default, no. It is an offline AI. You can plug in a web-search plugin via the API, but that breaks the "100% offline" privacy guarantee.
</details>

<details>
<summary><b>How do I report a bug?</b></summary>

Open an issue on the GitHub repository. Include your OS, hardware specs (CPU/GPU/RAM), and the model you were using.
</details>
